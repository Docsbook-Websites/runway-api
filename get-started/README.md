## Before you start

You need a Runway developer account and a payment method. The API is not available on a free tier — credits cost $0.01 each, with a $10 minimum first purchase.

Once you have a key, everything else on this site is reference material. The two pages you will come back to most are [Models](../models/README.md) (what to call) and [Pricing](../pricing/README.md) (what it costs).
